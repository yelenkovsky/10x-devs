# 10xUsage - MVP ideas

### Main problem
Manually creating high-quality vocabulary flashcards — ones that teach typical use of a word or phrase (context, collocation, grammar pattern), not “C1/C2-sounding” sentences — is time-consuming, which discourages using spaced repetition.

### Smallest feature set
- AI generation of flashcards from a pasted word list or short text (copy-paste)
- Manual flashcard creation
- Browse, edit, and delete flashcards
- Simple user accounts to store flashcards
- Integration with a ready-made spaced-repetition algorithm
- MVP card: cloze (gapped sentence) + word/phrase + full sentence + short definition + collocation/pattern + Polish translation

### What is NOT in the MVP
- A custom, advanced spaced-repetition algorithm (like SuperMemo, Anki, RemNote)
- Import of many formats (PDF, DOCX, etc.)
- Sharing flashcard decks between users
- Integrations with RemNote / Anki / other learning platforms
- Mobile apps (web only at first)
- Pronunciation scoring and AI conversation (speaking desk)

### Success criteria
- 75% of AI-generated flashcards are accepted by the user
- Users create 75% of flashcards with AI
